Quem somos?

O Mundo dos Esportes é um projeto desenvolvido pelo aluno Lucas André Batista na aula de Programação Web I, no IF Sul de Minas de Poços de Caldas, email para contato: lucas.batista@alunos.ifsuldeminas.edu.br . Temos o objetivo de apresentar informações sobre diferentes modalidades esportivas, suas histórias, características e competições.

O site reúne conteúdos sobre esportes populares e modalidades conhecidas internacionalmente, permitindo que os visitantes explorem diferentes aspectos do universo esportivo.

Objetivo do projeto

Nosso objetivo é organizar e apresentar informações esportivas de maneira clara, acessível e visualmente agradável, incentivando o conhecimento sobre as diferentes modalidades.

O que você encontra no site?

  • História e curiosidades sobre os esportes.
  • Informações sobre futebol, basquete, vôlei e cricket.
  • Conteúdo sobre a Copa do Mundo.
  • Galeria de fotografias esportivas.
  • Vídeos sobre a história do Corinthians.
  • Tabela comparativa entre esportes.

Desenvolvimento do site

O projeto foi desenvolvido utilizando HTML5 e CSS3. O HTML organiza o conteúdo e a estrutura das páginas, enquanto o CSS define as cores, os espaçamentos, a tipografia e a adaptação para diferentes tamanhos de tela.

A navegação entre as páginas permite explorar os conteúdos de maneira organizada.
